# 数据完整性检查

用在任何“变化解读”之前。完整性是结论可信度的前提，不是脚注。

1. **三态判断**：完整、已知不完整、未知。只有平台判定为完整时才当作完整；用户口头
   声称完整不构成依据。
2. **期间对齐**：基准与当前期间必须等长且都落在数据覆盖范围内。当前期间尚未结束时，
   不要与完整期间直接比较而不加说明。
3. **缺口要说清位置**：哪些天、哪些维度缺数据；只说“数据可能不完整”没有用。
4. **不完整时的表达**：以部分结果的语气呈现，明确哪些结论不受影响、哪些需要补齐后再
   看；不要用“预计”“大概”填补缺口。
5. **不重复计算**：同一维度在多张表出现时，确认口径一致后再比较；口径不同的表不能
   直接相加。

检查完成后，把结论和它的依据一起说清楚，再进入变化解读。
