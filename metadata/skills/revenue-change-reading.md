# 收入变化解读

用于回答“收入为什么变化”这类问题。按下面的顺序推进，任何一步证据不足就停在那一
步，不要跳到结论。

1. **先确认口径**：期间是否等长、时区是否为指标的业务时区、比较关系是显式区间还是
   环比/同比。缺任何一项就先问，不要用页面默认值代替。
2. **再看完整性**：数据是否完整到当前期间。已知不完整时结论按“部分结果”呈现，并说明
   缺口落在哪里；无法判断完整性时也要说明这是未知，而不是当作完整。
3. **看总量变化是否显著**：在平台判定的实质性阈值内，应回答“没有需要解释的变化”，
   不要为了给结论而挑一个片段。
4. **再定位来源**：优先看国家与平台两个维度的贡献排序；指标本身支持广告网络等更多维度
   时再逐层展开。平台给出的贡献分解是统计归因，说明变化集中在哪些片段，不证明因果。
5. **区分相关与因果**：只有当指标契约声明了驱动分解（例如展示量与 eCPM 的拆分）时，
   才能解释“是量还是价”的方向；否则只说贡献分布。

回答时引用已完成分析的证据，不自行计算或引用未出现在分析结果中的数字。
